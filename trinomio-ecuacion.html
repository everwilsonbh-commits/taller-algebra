3 · Trinomios x² + bx + c

Dos números que sumen b y multipliquen c.

x² + 7x + 12

3 + 4 = 7; 3 · 4 = 12 → (x + 3)(x + 4)

x² + x − 6

3 + (−2) = 1; 3 · (−2) = −6 → (x + 3)(x − 2)

x² − 8x + 15

(−3) + (−5) = −8; (−3)(−5) = 15 → (x − 3)(x − 5)

Regla de signos

c > 0: mismo signo, el de b.

c < 0: signos distintos; el mayor en valor absoluto lleva el signo de b.

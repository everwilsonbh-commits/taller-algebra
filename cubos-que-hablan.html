    Fábrica de fórmulas

    Pausa activa (5 min): brazos arriba para +, abajo para −, mientras el docente dicta (a − b)³. Luego, a fabricar fórmulas sin cubo.

    Ya conocen (a + b)³. Sin armar otro cubo, ¿cómo obtienen (a − b)³?

    Lo que descubrimos
    (a + b)³ = a³ + 3a²b + 3ab² + b³
    (a − b)³ = a³ − 3a²b + 3ab² − b³

    Forma corta, muy útil en concursos: (a + b)³ = a³ + b³ + 3ab(a + b)

    (x + 2)³ es igual a…

    Desarrolla (x − 1)³. ¿Cuál es el coeficiente de x?

    El examen con errores

    Cada equipo recibe el examen resuelto de un estudiante ficticio con 4 errores. Gana el primer equipo que los encuentra y los corrige. Al corregirlos van a descubrir la suma y la diferencia de cubos.

    a³ + b³ = (a + b)(a² − ab + b²)
    a³ − b³ = (a − b)(a² + ab + b²)

    Verificador

    Cambia los valores. ¿Se cumple siempre?

    Detectives del error

    Caso 1: a³ + b³ = (a + b)³

    Detectives del error

    Caso 2: x³ − 8 = (x − 2)(x² − 2x + 4)

    Detectives del error

    Caso 3 (¡cuidado!): x³ + 27 = (x + 3)(x² − 3x + 9)

    Detectives del error

    Caso 4: (2x − 1)³ = 8x³ − 12x² + 6x + 1

    Reto de concurso · 25 min

    Reto ONEM con apuestas

    Antes de cada reto, el equipo apuesta cuántos puntos arriesga (de 1 a 3): si acierta los gana, si falla los pierde. Cada pista resta medio punto.

    Si a + b = 5 y ab = 3, calcula a³ + b³.

    Pista: (a + b)³ = a³ + b³ + 3ab(a + b). Reemplaza lo que conoces.

    Calcula 1001³ − 999³ sin calculadora.

    Pista: a³ − b³ = (a − b)(a² + ab + b²) con a = 1001 y b = 999. Y 1001 · 999 = 1000² − 1.

    Bonus

    Bonus: si x − 1/x = 2, calcula x³ − 1/x³.

    En el reto 1, ¿por qué conviene no buscar a y b? ¿Qué ventaja tiene usar la identidad?
